# Metadados do registro no Zenodo (DOI)

Textos prontos para colar nos campos do depósito no Zenodo.
Estratégia: **inglês como base** (para indexação e citação internacional) +
**português** (para honrar o caráter do projeto e o público brasileiro).
DOI concept: `10.5281/zenodo.20617042`.

---

## Title

```
Musæum: an interactive digital library of Ancient Egyptian literature / biblioteca digital interativa de literatura do Egito Antigo
```

> O Zenodo tem um único campo de título. Por isso o bilíngue vai junto, separado
> por barra. Se preferir só um idioma no título, use o inglês e deixe o
> português no início da descrição.

---

## Description / Abstract

Cole no campo *Description* (ele aceita HTML básico, então os parágrafos abaixo
funcionam):

```html
<p><strong>Musæum</strong> is an interactive, bilingual (English/Portuguese)
digital library of literary texts from Ancient Egypt's Middle Kingdom
(2055–1650 BCE). An academic project devoted to democratizing access to ancient
Egyptian texts that usually circulate only in university settings, built with
bibliographic rigor and fidelity to the original sources.</p>

<p><strong>Musæum</strong> é uma biblioteca digital interativa e bilíngue
(português/inglês) de textos literários do Egito Antigo do Reino Médio
(2055–1650 AEC). Projeto acadêmico voltado a democratizar o acesso a textos
egípcios antigos que normalmente só circulam em ambientes universitários, com
rigor bibliográfico e fidelidade às fontes originais.</p>
```
