Sinais bilíteros essenciais

Os sinais bilíteros representam duas consoantes de uma vez. Allen explica que funcionam pelo princípio do rébus: a imagem de uma "casa" (𓉐) foi usada para representar os sons pr porque a palavra egípcia para "casa" começava com essa combinação. Os 20 aqui são os mais frequentes em textos reais do Egito Antigo — entre eles alguns trilíteros e logogramas fundamentais.

Regra dos complementos fonéticos (Allen, §3.2): Um unilítero que vem após um bilítero é quase sempre complemento fonético, não uma letra adicional. Exemplo: 𓉐𓂋 = pr (não prr) — o 𓂋 apenas confirma o r final do bilítero. Para escrever prr de verdade, seriam necessários dois sinais 𓉐.
